# PlayStation 5 hook

PlayStation builds need Sony's licensed SDK and an approved PlayStation Partners account.

This platform is **Request access**: its tools are licensed by the platform holder, so Kit can't include them. In **Export**, the card's **Request access** button opens the application page.

Once you're approved, install the licensed Kit hook for this platform into `hooks/ps5/` next to the Kit editor. Its `hook.toml` adds an `[export]` command, and the card turns **Ready**.

## Requirements

- Approval from Sony Interactive Entertainment
- The PS5 SDK and development kit
- The Kit PS5 hook, installed into hooks/ps5
