# Nintendo Switch hook

Switch builds need Nintendo's licensed SDK and an approved Nintendo Developer Portal account.

This platform is **Request access**: its tools are licensed by the platform holder, so Kit can't include them. In **Export**, the card's **Request access** button opens the application page.

Once you're approved, install the licensed Kit hook for this platform into `hooks/switch/` next to the Kit editor. Its `hook.toml` adds an `[export]` command, and the card turns **Ready**.

## Requirements

- Approval from Nintendo
- The Nintendo SDK and development hardware
- The Kit Switch hook, installed into hooks/switch
