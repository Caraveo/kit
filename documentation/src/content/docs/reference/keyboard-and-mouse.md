---
title: Keyboard & mouse
description: Default editor shortcuts and how to rebind them.
---

Open **Project → Project Settings → Editor Controls** to change keys, alternate
bindings, and pointer gestures. Changes apply to the editor on this computer.
Choose **Reset all controls** to restore the bindings below.

| Action | Shortcut |
|---|---|
| Play / stop | <kbd>F5</kbd> |
| Save scene (or the script, in the code editor) | <kbd>Ctrl</kbd> + <kbd>S</kbd> |
| Undo / redo | <kbd>Ctrl</kbd> + <kbd>Z</kbd> / <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Z</kbd> |
| Pan | Drag (left or middle button) |
| Orbit | Right drag, or <kbd>Shift</kbd> + drag |
| Zoom | Scroll, or hold <kbd>W</kbd> / <kbd>S</kbd> (mouse over the viewport) |
| Pan left / right | Hold <kbd>A</kbd> / <kbd>D</kbd>; <kbd>Q</kbd> / <kbd>E</kbd> down / up; add <kbd>Shift</kbd> to go faster |
| Select | Click (in the object list, it also frames the object) |
| Frame selection | <kbd>F</kbd> or double-click |
| 2D / 3D view | <kbd>T</kbd> |
| Wireframe | <kbd>1</kbd> |
| Lighting | <kbd>2</kbd> |
| Grid | <kbd>3</kbd> |
| Collider outlines | <kbd>4</kbd> |
| Canvas mode (draw paths; Shift + drag starts over; drag a dot to move it) | <kbd>5</kbd> |
| Volumes preview ([post-processing](/editor/post-processing/)) | <kbd>6</kbd> |
| [Diagram view](/editor/diagrams/) (visual logic for the selected object) | <kbd>7</kbd> |
| [Rex](/editor/rex/), the AI puppy | <kbd>8</kbd> |
| In the Diagram view: add a node / delete / duplicate / undo | Right-click · <kbd>Del</kbd> · <kbd>Ctrl</kbd> + <kbd>D</kbd> · <kbd>Ctrl</kbd> + <kbd>Z</kbd> |
| Auto-rotate | <kbd>R</kbd> |
| Rename | <kbd>F2</kbd> or double-click in the object list |
| Duplicate | <kbd>Ctrl</kbd> + <kbd>D</kbd> |
| Delete | <kbd>Del</kbd> |
| Console | <kbd>`</kbd> |
| Release game keyboard / leave Canvas | <kbd>Esc</kbd> |
| All shortcuts | <kbd>F1</kbd> |

**In a running game:** <kbd>F11</kbd> toggles fullscreen.
